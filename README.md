# Eternia Aurora Sovereign Engine

by Artiore

ETERNIA · AURORA is a local-first generative ambient instrument. Shape evolving rhythms, cosmic tones, and spacious soundscapes in your browser. It is a single-file, local-first instrument: everything runs in the page you open, with no server and no account.

Play it: https://artiais.com/eternia-aurofa-soverign-engine/

To run it locally, open `index.html` in a browser.
